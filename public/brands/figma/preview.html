Guidelines

Do's & Don'ts

Do — Embrace
  • Canvas White (#ffffff) as primary background
  • Figma Blue (#0d99ff) for all interactive elements
  • Charcoal (#1e1e1e) for primary text
  • 8px grid for all spacing decisions
  • 6px radius for buttons, 12px for cards
  • Smoke (#e5e5e5) for all borders
  • Clean whitespace as a design element
Don't — Avoid
  • Figma Blue for large background areas
  • Inconsistent border radius values
  • Dark backgrounds with white text
  • Decorative gradients on functional UI
  • Colors outside the defined palette
  • Dense layouts without 8px spacing
  • Monospace fonts for body text
