Guidelines

Do's & Don'ts

Do — Embrace
  • Parchment White (#faf9f7) as primary background for warmth
  • Cloud (#ffffff) for all elevated surfaces
  • Amber (#d97706) exclusively for accents and interactive elements
  • 1.75 line height for conversation body text
  • Rounded corners (minimum 6px) on all elements
  • 4px-based spacing with generous breathing room
  • Inter for all text, Inter Mono for code only
Don't — Avoid
  • Cool grays (blue-tinted) — use warm stone neutrals
  • Amber for body text or large surface fills
  • Sharp corners (< 6px) on any element
  • Heavy drop shadows — use borders instead
  • Dense packing without generous spacing
  • Decorative or display fonts
  • Rose outside error states and destructive actions
