Guidelines

Do's & Don'ts

// do
  • Forge Black (#1B1B1B) as primary canvas background
  • Cursor Teal (#00D4AA) for active states and primary CTAs
  • JetBrains Mono for all code and terminal content
  • Compact spacing with 4px base unit
  • Small border radii (4-8px) for editor feel
  • Smoke (#9B9B9B) for metadata and timestamps
  • Flat design — borders over shadows
// don't
  • Bright or saturated background colors
  • Cursor Teal for body text or large surfaces
  • Decorative drop shadows or gradients
  • Generous spacing — favor density
  • Serif or display fonts in the system
  • Error Red for non-error contexts
  • Large border radii (keep it angular)
